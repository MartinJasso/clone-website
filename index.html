truth-tophraphy protocol

Anyone can join g-truth and fork a daily branch of meaning.

Login with Gmail or any gauth-compatible identity. Every day each branch appends its prompt to the previous network prompt, then the aggregated truth-stream is sent to Gemini.

Your node: rx-g-truth.com/branch-name/...

How the daily branching loop works

1. Authenticate

Join the network instantly using Gmail or gauth. Every identity can create or join branches.

2. Append your prompt

Each branch adds today's intent to yesterday's inherited branch prompt.

3. Aggregate + transmit

The branch graph is merged into a single aggregated prompt package and relayed to Gemini.

4. Publish branch output

Results are written back to branch endpoints and remain discoverable in their URL lineage.

Branch routing format

Canonical path

rx-g-truth.com/branch-name/day-042

Prompt inheritance

prompt[today] = prompt[parent] + prompt[branch]

Network label

The protocol network is called g-truth.
